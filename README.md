# Mi patrimonio · dashboard local

> 🚧 **En desarrollo.** Todavía no está lista para usarse: pronto habrá instrucciones completas.

Panel para seguir tu patrimonio neto (fondos, ETFs, acciones, cripto, planes de pensiones,
efectivo, inmuebles…) que funciona **en tu propio ordenador**: tus datos no salen de él.

La cartera de ejemplo que trae es la cartera real del autor, con fines divulgativos.

**Aviso:** herramienta informativa. No es asesoramiento financiero ni una recomendación de
inversión. No se garantiza la exactitud de los datos ni de los precios.
